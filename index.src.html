How it works

  
Claude writes the words. Your data and the checks decide what is true.

  

    
01 · youYour internal dataRead-only access to the tables or API behind your report. Nothing is copied that the report does not need.

    
02Facts firstCode works out the stage, dates, countdowns and amounts. Claude never has to calculate, so it cannot miscount.

    
03Claude writes to a schemaStructured output: headline, summary, what happens next, actions, timeline, glossary. Same shape every time, so your page can render it.

    
04Checked, then shownEvery figure and name traced, reading level scored, advice phrasing blocked. A failed check shows the plain record view and logs it.

  






  
Under the hood

  

    
claude-report-1027/
├─ index.html          the studio you just used
├─ src/caseReport.js   facts, draft, checks, request, render
├─ data/records.json   two invented court records
└─ tests/
   ├─ verify.js        61 engine checks
   └─ browser-check.py clicks through this page

    

      
The page and the tests load the same engine file. The tests also prove the drafted report fits the exact JSON schema the Claude request sends, and that every kind of mistake a model can make here (wrong date, wrong amount, invented name, missing hearing, advice) is caught.
